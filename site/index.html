Approval Stamp · 결재 도장

Put your own stamp or signature image on a PDF or image by hand, then export the stamped file.

GuidePrivacyTermsSupportSource

English · 한국어

Install

Claude (web, desktop, mobile)

  1. Open Settings → Connectors → Add custom connector.
  2. Name it Approval Stamp and enter https://approval-stamp-mcp.vercel.app/mcp. No sign-in is needed.
  3. In a chat, turn it on under + → Connectors.

On Team and Enterprise plans an organisation owner may need to add the connector first.

ChatGPT

  1. Settings → Apps → Advanced settings: turn on Developer mode.
  2. Create app: MCP server URL https://approval-stamp-mcp.vercel.app/mcp, authentication None.

Claude Code · Codex · other MCP clients

Add the remote MCP server (Streamable HTTP) at https://approval-stamp-mcp.vercel.app/mcp, for example claude mcp add --transport http approval-stamp https://approval-stamp-mcp.vercel.app/mcp. The interactive UI shows only in hosts that support MCP Apps.

How to use

  1. Ask: Open the approval stamp app.
  2. Open, paste or drop a PDF or an image (PNG, JPEG, WebP).
  3. Add your stamp image once. A photo or scan is fine: the white background is made transparent and the image is cropped.
  4. Hover to preview, click to stamp. Drag to move, use the corner handle to resize, Delete to remove, Ctrl+Z to undo. Size is set in mm.
  5. Export saves the original PDF with the stamp added (text stays text), or the image in its original size and format.

Tools

ToolWhat it does
open_stampOpens the stamp app. There is deliberately no tool that places a stamp: you read the document and stamp it yourself.

Good to know

  • Encrypted or password-protected PDFs are refused. Digitally signed PDFs open with a warning, because adding a stamp invalidates the existing signature.
  • Some scanned PDFs with JPEG 2000 or JBIG2 images may look blank in the preview; the export still keeps them.

Your data

  • The document. Stays in your browser, inside the app. It is never uploaded to our server and never shared with the AI model.
  • Your stamp images. Kept in your browser's local storage on your device so you can reuse them. They are never sent to our server or to the AI model. Remove a stamp in the app, or clear the site data, to delete it.
  • What the agent sees. After you export, the app tells the chat's AI model one line, for example 3 stamps on pages 1, 2 of a 4-page document. No document content, file name or stamp image.

설치

Claude (웹, 데스크톱, 모바일)

  3. 대화에서 + → 커넥터에서 켜고 사용합니다.

Team, Enterprise 플랜은 조직 소유자가 먼저 커넥터를 추가해야 할 수 있습니다.

ChatGPT

  1. 설정 → 앱 → 고급 설정에서 개발자 모드를 켭니다.
  2. 앱 만들기에서 MCP 서버 URL에 https://approval-stamp-mcp.vercel.app/mcp, 인증은 없음을 고릅니다.

Claude Code · Codex · 기타 MCP 클라이언트

원격 MCP 서버(Streamable HTTP) 주소 https://approval-stamp-mcp.vercel.app/mcp를 추가합니다. 예: claude mcp add --transport http approval-stamp https://approval-stamp-mcp.vercel.app/mcp. 화면(UI)은 MCP Apps를 지원하는 앱에서만 보입니다.

사용법

  1. 결재 도장 앱 열어 줘라고 요청합니다.
  2. PDF나 이미지(PNG, JPEG, WebP)를 열거나 붙여넣거나 끌어다 놓습니다.
  3. 내 도장 이미지를 한 번 추가합니다. 사진이나 스캔도 됩니다. 흰 배경은 투명해지고 여백은 잘립니다.
  4. 마우스를 올리면 미리 보이고, 클릭하면 찍힙니다. 끌어서 옮기고, 모서리 손잡이로 크기를 바꾸고, Delete로 지우고, Ctrl+Z로 되돌립니다. 크기는 mm 단위입니다.
  5. 내보내기는 원본 PDF에 도장만 더한 파일(글자는 글자 그대로), 또는 원래 크기와 형식의 이미지를 저장합니다.

도구

도구하는 일
open_stamp도장 앱을 엽니다. 도장을 찍는 도구는 일부러 없습니다. 문서를 읽고 직접 찍는 것이 목적입니다.

알아 둘 점

  • 암호가 걸린 PDF는 열지 않습니다. 전자서명된 PDF는 경고와 함께 열립니다. 도장을 더하면 기존 서명이 무효가 되기 때문입니다.
  • JPEG 2000이나 JBIG2 이미지가 든 일부 스캔 PDF는 미리보기가 비어 보일 수 있지만, 내보낸 파일에는 그대로 남습니다.

데이터

  • 문서. 브라우저의 앱 안에만 있습니다. 저희 서버로 올라가지 않고 AI 모델에도 공유되지 않습니다.
  • 도장 이미지. 다시 쓸 수 있도록 내 기기 브라우저의 로컬 저장소에 보관됩니다. 저희 서버나 AI 모델로 보내지 않습니다. 앱에서 도장을 지우거나 사이트 데이터를 지우면 삭제됩니다.
  • 에이전트가 보는 것. 내보낸 뒤 앱은 채팅의 AI 모델에 한 줄만 알립니다. 예: 4쪽 문서의 1, 2쪽에 도장 3개. 문서 내용, 파일 이름, 도장 이미지는 보내지 않습니다.
